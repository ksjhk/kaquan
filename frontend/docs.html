开放平台接入指引（签名鉴权）

面向 B 端代理商的对外开放业务 API（v1 组）：货源查询、商品详情、余额查询、创建订单（余额扣款）、订单查询。货源查询类接口公开可调用，无需签名（同 IP 限 60 次/分钟）；交易类接口（下单、订单查询、余额查询）需注册创建密钥后签名调用，使用控制台创建的密钥对（app_key / app_secret）。

第一步：创建密钥

注册开放平台账号后，进入 控制台 →「API密钥」→ 创建密钥，得到 app_key（ak_ 开头）和 app_secret（sk_ 开头，仅创建时完整展示一次，请立即保存）。

接口地址

所有业务接口统一走：https://your-domain.com/open-api/v1/

鉴权参数（每个请求必带）

参数名类型必填描述
app_keystring是控制台创建的 AppKey
timestampnumber是秒级 Unix 时间戳，与服务器时间差超过 10 分钟将被拒绝
signstring是签名串，算法见下

签名算法

1. 取除 sign 外的所有请求参数（含 app_key、timestamp 及业务参数），空值参数跳过不参与；
2. 按参数名升序排序，拼接为 k1=v1&k2=v2 形式；
3. 末尾追加 &secret=app_secret；
4. 对整串做 MD5（32 位小写）即为 sign。

// 示例：假设业务参数 goods_id=4251 // 待签名串： app_key=ak_demo123&goods_id=4251&timestamp=1792464645&secret=sk_demoSecret sign = md5("app_key=ak_demo&goods_id=4251&timestamp=1792464645&secret=sk_demoSecret") = "9a8b7c6d5e4f3021123456789abcdef0" // 示例值

curl 请求示例（以余额查询为例）

curl "https://your-domain.com/open-api/v1/balance?app_key=ak_demo123&timestamp=1792464645&sign=9a8b7c6d5e4f3021123456789abcdef0"

返回示例（示例）

{ "code": 0, "message": "操作成功", "data": { "balance": 128800 } }
签名错误、时间戳超窗、密钥被禁用都会返回非 0 code 及对应 message；请妥善保管 app_secret，不要放在前端页面或客户端代码中。

货源接口 公开接口，无需签名

查询平台在售卡券货源，用于你自己的商城/系统选品展示。注意：本组接口金额字段单位均为「分」（如 cost_price=2877 表示 28.77 元）。

1. 货源列表 （公开接口，无需签名，匿名 price_rate=1）

GEThttps://your-domain.com/open-api/v1/goods
参数名示例值类型必填描述
category_id667number否分类 id，缺省取全部
current1number否页码（默认 1）
size20number否每页数量

（鉴权参数 app_key / timestamp / sign 必带，下同）

curl 请求示例

curl "https://your-domain.com/open-api/v1/goods?category_id=667&current=1&size=20&app_key=ak_demo123&timestamp=1792464645&sign=xxxxxxxx"

返回示例（示例）

{ "code": 0, "message": "操作成功", "data": { "list": [ { "goods_id": 4251, "goods_name": "爱奇艺星钻会员月卡", "goods_img": "https://your-cdn-domain.com/images/poster/xxx.png", "face_value": 6000, "cost_price": 2877, "sell_price": 6000, "stock_num": 9999 } ], "pagination": { "total": 131, "size": 20, "current": 1, "pages": 7 } } }

2. 商品详情 （公开接口，无需签名，匿名 price_rate=1）

GEThttps://your-domain.com/open-api/v1/goods/detail
参数名示例值类型必填描述
goods_id4251number是货源列表返回的 goods_id

curl 请求示例

curl "https://your-domain.com/open-api/v1/goods/detail?goods_id=4251&app_key=ak_demo123&timestamp=1792464645&sign=xxxxxxxx"

返回示例（示例）

{ "code": 0, "message": "操作成功", "data": { "goods_id": 4251, "goods_name": "爱奇艺星钻会员月卡", "goods_img": "https://your-cdn-domain.com/images/poster/xxx.png", "face_value": 6000, "cost_price": 2877, "sell_price": 6000, "stock_num": 9999 } }

字段说明

字段类型描述
goods_idnumber规格商品 id（下单必传）
goods_namestring商品名称
goods_imgstring商品主图（完整 URL）
face_valuenumber面值（分）
cost_pricenumber成本价（分），下单时按此价从余额扣款
sell_pricenumber建议售价（分）
stock_numnumber库存数量

下单接口 需签名

创建订单即按商品成本价（cost_price）从你的账户余额扣款，账户没有余额将无法调用下单接口；余额不足时返回错误提示「余额不足，请充值」。

1. 创建订单

POSThttps://your-domain.com/open-api/v1/order/create
参数名示例值类型必填描述
goods_id4251number是规格商品 id
recharge_account13800138000string是充值账号（手机号类须 11 位手机号）

curl 请求示例

curl -X POST "https://your-domain.com/open-api/v1/order/create" \ -d "goods_id=4251" \ -d "recharge_account=13800138000" \ -d "app_key=ak_demo123" \ -d "timestamp=1792464645" \ -d "sign=xxxxxxxx"

返回示例（示例）

{ "code": 0, "message": "操作成功", "data": { "order_no": "OPEN20261020120000123456", "cost_price": 2877 } }

余额不足时（示例）

{ "code": 1001, "message": "余额不足，请充值", "data": null }

2. 订单查询 （需签名）

POSThttps://your-domain.com/open-api/v1/order/query
参数名示例值类型必填描述
order_noOPEN20261020120000123456string是下单返回的订单号

curl 请求示例

curl -X POST "https://your-domain.com/open-api/v1/order/query" \ -d "order_no=OPEN20261020120000123456" \ -d "app_key=ak_demo123" \ -d "timestamp=1792464645" \ -d "sign=xxxxxxxx"

返回示例（示例）

{ "code": 0, "message": "操作成功", "data": { "order_no": "OPEN20261020120000123456", "goods_name": "爱奇艺星钻会员月卡", "status": 3, "status_txt": "已到账", "recharge_account": "13800138000", "created_time": "2026-10-20 12:00:00" } }
订单状态码含义与下方「附录：订单状态表」一致；充值中的订单建议每 5-10 秒轮询一次。

余额查询 需签名

查询当前账户可用余额，单位为「分」（如 balance=128800 表示 1288.00 元）。

GEThttps://your-domain.com/open-api/v1/balance

请求参数：仅鉴权参数（app_key / timestamp / sign）。

curl 请求示例

curl "https://your-domain.com/open-api/v1/balance?app_key=ak_demo123&timestamp=1792464645&sign=xxxxxxxx"

返回示例（示例）

{ "code": 0, "message": "操作成功", "data": { "balance": 128800 } }
下单接口按成本价实时扣减余额，请保持账户余额充足；余额不足时下单接口将返回「余额不足，请充值」。
